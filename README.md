# 🎬 MovieMate – Movie Browsing & Recommendation System

MovieMate is a full-stack MERN application that allows users to browse, search, and manage their favorite movies. It provides a modern and responsive interface with secure authentication and personalized movie management.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 🎥 Browse Movies
- 🔍 Search Movies
- ❤️ Like & Dislike Movies
- 📌 Add Movies to Watchlist
- 🎞️ Watch Movie Trailers
- 📱 Responsive Design
- ⚡ Fast React + Vite Frontend

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/ShreyaMalode/Internship-Project.git
```

### Install Backend

```bash
cd "Backend MovieMate"
npm install
```

### Install Frontend

```bash
cd "../MovieMate-Frontend"
npm install
```

### Run Backend

```bash
npm start
```

### Run Frontend

```bash
npm run dev
```
